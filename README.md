# Nonlinear Mechanical Metamaterials

Computational study of nonlinear wave dynamics in a discrete sine-Gordon mechanical metamaterial.

The project explores:

- dispersion and the linear frequency bandgap
- kink and antikink solutions
- Lorentz contraction of moving kinks
- kink–kink and kink–antikink collisions
- localized energy transport
- stationary breathers
- breather validation against the analytical solution
- breather–breather scattering

The simulations are implemented in Python using NumPy and Matplotlib.
